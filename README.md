# Mushroom — Wireless Charger Landing Page

Exact interactive replica of the [Mushroom Wireless Charger landing page](https://mushroom-landing.webflow.io/) by Shakuro.

## Project Structure

- `index.html` — Modular HTML file linking to `css/styles.css`, `js/main.js`, and `assets/`
- `css/styles.css` — Custom styles, vertical-slice typography reveal animations, and layout rules
- `js/main.js` — Scroll-driven parallax, 3D exploded charger controller, USB-C wireframe animation, and interactive Preorder modal
- `assets/` — All 3D studio-rendered transparent WebP charger layers and lifestyle gallery JPEG images
- `mushroom-landing-standalone.html` — Single-file self-contained version with all images embedded as base64 data URIs
